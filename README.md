# 📊 SWYNEX Final Data Analytics Project – Employee Analytics

## 📌 Project Overview

This project was completed as part of my internship with **SWYNEX Technologies**.

The project presents an end-to-end Data Analytics case study using an employee dataset. The workflow covers data cleaning, exploratory data analysis, data visualization, Power BI dashboard development, business insights, and recommendations.

The objective is to transform raw employee data into meaningful information that can support data-driven business decisions.

---

## 🎯 Objectives

- Clean and prepare employee data
- Identify and handle missing values
- Check duplicate records
- Perform Exploratory Data Analysis
- Analyze employee demographics
- Analyze department and regional distribution
- Analyze salary patterns
- Analyze employee performance
- Analyze remote-work patterns
- Develop an interactive Power BI dashboard
- Generate meaningful business insights
- Provide data-driven recommendations

---

## 🧹 Data Cleaning

The following data-cleaning steps were performed:

1. Loaded the employee dataset using Pandas.
2. Checked rows and columns.
3. Inspected data types.
4. Checked missing values.
5. Checked duplicate records.
6. Handled missing values.
7. Separated Department and Region information.
8. Converted Join Date into datetime format.
9. Standardized categorical values.
10. Validated numeric fields.
11. Performed final data-quality checks.
12. Exported the cleaned dataset.

### Data Quality Result

- Total Records: **1,020**
- Duplicate Records: **0**
- Remaining Missing Values: **0**

## 💡 Key Business Insights

### 1. Department Distribution

DevOps has the highest number of employees with **189 employees**, while Cloud Tech has **146 employees**.

### 2. Regional Distribution

California has the highest employee count with **187 employees**.

### 3. Remote Work

There are **513 remote employees** and **507 non-remote employees**, showing an almost equal distribution.

### 4. Employee Performance

The **Good** performance category contains the highest number of employees with **269 employees**.

### 5. Joining Trends

The year **2023** recorded the highest number of employee joinings with **228 employees**.

### 6. Salary Analysis

Sales has the highest average departmental salary at approximately **₹86,874**.
